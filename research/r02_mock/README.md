# R02 lattice mock renderer

A Python stand-in for TradingView, used only to judge by eye how the planned `indicators/R02OddsLattice.pine` will look (docs/R02_PLAN.md §5). It is not a test of R02. `nodes.py` builds the 41 {2,3} odds nodes with exact Fractions (§1). `engine.py` runs the §2 event contract on Binance BTCUSDC M1 klines: day eligibility and the hygiene gate, publication at 00:01, the M1 path, freshness, Wilder ATR14 and REJECT/BREAK/INDETERMINATE/CENSORED outcomes. `render.py` draws the §3 visual spec on a TradingView dark-theme M15 chart mimic, 2400 px wide. Run it with `python3 -I research/r02_mock/run.py <dir of BTCUSDC-1m-YYYY-MM-DD.csv files> <out dir> [--source binance.vision] [--preview-ineligible YYYY-MM-DD:reason]`. It writes `mock_day_full.png`, `mock_zoom_reject.png`, `mock_zoom_break.png`, `mock_ineligible.png` and `checks.json`. The optional `extra_ineligible_style_preview.png` forces one day ineligible, only so the dimmed style can be seen. Requires matplotlib.
